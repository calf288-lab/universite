# ИИ-ассистент РОПа: контроль 100% диалогов менеджеров вместо 20% и возврат до 288 000 ₽ выручки в месяц

РОП проверяет выборку. Остальные диалоги живут без обратной связи: менеджер пропускает этапы скрипта, не фиксирует следующий шаг, отвечает через часы, и лид уходит к конкуренту. Связка n8n + LLM анализирует каждый диалог по чек-листу, считает метрики по менеджерам и присылает РОПу алерты в Telegram.

## Проблема: РОП видит выборку, потери происходят в остальном

**Допущения модели** (заменить данными клиента):
- Мебельный салон, 200 лидов в месяц, 3 менеджера.
- Средний чек 120 000 ₽.
- РОП проверяет ≈ 20% диалогов. Остальные 80% остаются без контроля.

| Тип потери | Как выглядит | Почему РОП не видит |
|---|---|---|
| Задержка ответа | Лид написал вечером, ответ утром | Время первого ответа не считается |
| Пропуск этапов скрипта | Не выяснили бюджет и срок | Нужно читать диалог целиком |
| Нет следующего шага | Диалог закончился на «подумайте» | Выглядит как нормальное завершение |

## Решение: ИИ-ассистент РОПа на n8n + LLM

Ассистент разбирает каждый завершённый диалог по чек-листу компании и возвращает структурированную оценку с цитатами-доказательствами.

**Что анализируется:**
- Время первого ответа.
- Соблюдение скрипта (% обязательных этапов).
- Отработка возражений.
- Следующий шаг (дата и действие).
- Тон и токсичность.
- «Зависшие» лиды (> N часов без касаний).
- Полнота карточки CRM.

**Принципы работы:**
- Каждая оценка содержит цитату из диалога.
- Критерии задаёт РОП, а не LLM.
- Низкая уверенность модели → ручная проверка.
- Оценка ИИ не основание для санкций. Решение принимает человек.

## Архитектура

CRM (amoCRM / Bitrix24) → webhook → n8n → транскрипция/текст → LLM анализ → JSON (баллы + цитаты) → дашборд / Telegram алерты.

## Ручной контроль vs ИИ-анализ

| Параметр | Ручной контроль | ИИ-анализ |
|---|---|---|
| Охват диалогов | ≈ 20% | 100% |
| Задержка обратной связи | 1–2 недели | Минуты / дни |
| Единообразие оценки | Зависит от настроения | Один чек-лист |
| Доказательства | Память | Цитата и таймкод |

## Кейс: мебельный салон, +15% к конверсии (модельный расчёт)

При 200 лидах и чеке 120 000 ₽ рост конверсии с 8,0% до 9,2% дает +2,4 договора = **+288 000 ₽ в месяц**. При валовой марже 35% это 100 800 ₽ дополнительной прибыли. Срок окупаемости внедрения = стоимость внедрения / 100 800 ₽.
