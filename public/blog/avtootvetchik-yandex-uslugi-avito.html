Автоответчик для Яндекс Услуг и Авито: +64 800 ₽ выручки в месяц от ночных обращений

Клиент пишет в 23:00 сразу нескольким исполнителям и выбирает того, кто ответил первым. Мастер спит, утром заявка уже ушла другому. Бот на n8n с LLM отвечает за секунды, собирает параметры заказа и передаёт мастеру готовую карточку в Telegram.

Проблема: ночное обращение достаётся тому, кто ответил первым

Допущения модели: - 120 обращений в месяц. - 45% (54) приходят с 21:00 до 09:00. - Конверсия при ответе < 5 мин = 15%, при ответе утром = 5%.

Потеря: 5,4 заказа × 12 000 ₽ = 64 800 ₽ в месяц. Стоимость привлечения обращения падает с 2 381 ₽ до 1 667 ₽ (−30%).

Решение: бот на n8n + YandexGPT/Groq

Бот отвечает мгновенно, задает 3–5 уточняющих вопросов, называет утверждённую вилку цены и передаёт лид в Telegram/CRM.

Чего бот не делает: - Не называет точную цену и сроки. - Не обсуждает жалобы и споры. - Не пишет клиенту первым.

Схема работы

Авито: Сообщение → Webhook Messenger API → n8n → LLM квалификация → Ответ через API + Лид в CRM + Алерт мастеру. Яндекс Услуги: Уведомление (email/push) → IMAP триггер n8n → LLM черновик ответа → Мастер отправляет в один клик.

Ограничения и безопасность

  • 152-ФЗ: Данные хранятся в РФ. Для зарубежных моделей используется обезличивание или YandexGPT.
  • Спам: Бот отвечает только на входящие. Рассылки запрещены.
  • Handoff: При запросе человека, сложном вопросе или низкой уверенности модели диалог передаётся мастеру.
